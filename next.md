
 Технічне резюме проєкту (ESP32-S3 Round Weather Station)


1. Апаратна платформа та середовище

• Мікроконтролер: esp32-s3-devkitc-1 (8MB Flash, без PSRAM, частота 240MHz).
• Дисплей: Круглий IPS екран GC9B72 (360x360 пікселів) з апаратною інверсією кольорових каналів (BRG замість стандартного RGB).
• Середовище: PlatformIO (Arduino Framework), бібліотеки LovyanGFX та Adafruit DHT sensor library.
• Мовні правила проєкту: Спілкування у чаті ведеться українською мовою, але весь код, назви змінних, класів та коментарі всередині файлів пишуться виключно англійською мовою.

2. Розпіновка (src/config/config.h)

Усі піни винесено в єдиний централізований конфігураційний файл:
• Дисплей (SPI2_HOST): SCLK = 12, MOSI = 11, MISO = 13, DC = 9, CS = 10, RST = 8.
• Підсвітка дисплея (PWM): BL = 14 (частота 12000 Hz, канал 1).
• Датчик температури/вологості: DHT11 на піні 4.
• Керування та індикація: Кнопка перемикання екранів на піні 18 (INPUT_PULLUP), RGB-світлодіод на пінах R = 17, G = 16, B = 15.

3. Архітектура коду та модулі

Проєкт розділено на незалежні модулі за принципом Separation of Concerns:
• src/config/config.h — глобальні константи, розміри матриці та номери всіх пінів.
• src/display/display_lgfx.h — низькорівневий драйвер LGFX_GC9B72, підв'язаний до пінів із config.h.
• src/display/display_colors.h / .cpp — об'єктно-орієнтована палітра кольорів (DisplayColor з гетерами getRawCode(), getName(), getRgbString()), відкалібрована під BRG-матрицю. Містить 10 кольорів, розділених на два масиви: core_list (5 базових) та design_list (5 дизайнерських, включно зі спеціальним відтінком GRAPEFRUIT — RGB 252,90,44).
• src/peripherals/sensor_dht.h / .cpp — клас SensorDHT для неблокуючого опитування датчика раз на 2.5 секунди.
• src/display/ui_manager.h / .cpp — графічний менеджер UIManager. Використовує 16-бітний повноекранний спрайт (LGFX_Sprite) для усунення мерехтіння, рендерить 3 екрани (Головна метеостанція, Core Colors, Design UI Colors), підтримує 60 FPS анімацію заповнення шкали (Lerp) та згладжені шрифти (FreeSansBold).
• src/main.cpp — чистий диспетчер ініціалізації та опитування кнопки/датчика/анімації.

4. Поточний стан дизайну (Екран 1)

• Зовнішня ліва дуга: суцільний колір grapefruit із програмно заокругленими краями (через fillCircle на кінцях).
• Внутрішня дуга температури: колір cyan із плавною анімацією при старті, заокругленими краями та радіальними засічками спідометра.
• Центральний блок: векторна іконка (сонце з променями + хмаринка), статус CLOUDY, велика цифра температури з динамічним розрахунком відступу для знака градуса ° та літери C.
• Нижній блок: швидкість вітру (WIND: 14.5 m/s), вертикальна розділювальна лінія, праворуч від неї показники out: та in: один під одним. Внизу по центру (Y = 304) виводиться змінна _location_name (за замовчуванням "KYIV").

🚀 План на наступні етапи розробки

1. Завершити візуальну перевірку: Скомпілювати останню версію ui_manager.cpp (з виправленими масивами символів char num_buf, char hum_out_buf, char hum_in_buf) та заповнити порожню ліву секцію внизу (ліворуч від вертикальної лінії — наприклад, годинником або атмосферним тиском).
2. Інтеграція Wi-Fi та API погоди: Підключити ESP32-S3 до мережі, налаштувати NTP-час та запити до безкоштовного сервісу Open-Meteo для отримання реальної зовнішньої температури, вологості, швидкості вітру, коду погоди та назви міста.
3. Апаратна індикація: Задіяти вільний RGB-світлодіод (піни 15, 16, 17) для фонової індикації комфорту температури в кімнаті.
